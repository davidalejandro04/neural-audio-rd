Metrics and statistical interpretation

These definitions describe dsp.py, experiment.py, runtime.py, and listening.py as of 2026-10-21. See theory for model notation and experiments for thresholds and expected results.

1. What each metric measures

Metric Purpose Ideal / direction Important limitation
MSE Squared sample error; sensitive to large discrepancies 0; lower Sensitive to phase, gain, and alignment
L1 Absolute sample error 0; lower Does not isolate perceptual differences
ESR Error energy relative to target energy 0; lower Undefined on silence; level and phase sensitive
MR-STFT Magnitude mismatch over several time/frequency resolutions 0; lower Does not directly compare spectral phase
LSD RMS spectral magnitude discrepancy in dB 0 dB; lower Depends on magnitude floor and FFT configuration
Streaming/export error Numerical agreement between execution paths 0; lower Agreement can preserve a poor audio model
CPU deadline fraction Compute time relative to audio block duration Lower; required p99 Python screening does not establish callback safety
ABX accuracy Ability to discriminate target/model under a listening condition Chance is 0.5 A nonsignificant result does not prove equivalence

No current objective metric is a calibrated perceptual-quality score. Report complementary metrics, audio examples, and the evaluation conditions together.

2. Waveform metrics — implemented

The implementation returns JSON null for undefined ESR, without inserting an epsilon in its ratio. Silence is assessed with absolute errors instead. For ordinary non-silent signals, ESR 1 means error energy equals target energy; ESR 0.1 means error energy is one tenth of target energy. This is not equivalent to a particular listening score.

An optional reporting conversion is dB; it is not a field currently emitted by the code. ESR zero would become negative infinity, so such a conversion needs a declared display floor. Current ESR has no pre-emphasis, DC removal, gain fitting, or time-shift optimization.

This differs from pooling all samples or taking a median of pair metrics. by_regime_pair_median separately reports pair medians within seen/held-out control regimes, without the source-mean step.

The evaluator reports three systems when appropriate:

  • Model: the learned processor.
  • Identity: , a meaningful check that learning improves on doing nothing.
  • Analytic oracle: the known synthetic generating function, included when the synthetic dataset marker is present. This is a target-integrity control, not an unknown-device model learned from examples. Imported captures have no such oracle.

Bypass pairs are excluded from quality summaries so exact identity behavior cannot inflate quality. The filter is exactly mix greater than zero; it does not inspect whether a target otherwise equals identity. Undefined per-pair ESR is omitted from metric aggregation. A quality gate fails if its model/identity aggregate is undefined.

Validation selection uses a different statistic: the arithmetic mean active validation-pair ESR. It rejects active validation examples with undefined ESR. Hyperparameters and checkpoints must not be selected using final test results.

6. Listening and inferential statistics

6.1 Current ABX tooling — implemented

Packaging uses A = target, B = model, and X = a seeded random choice of A or B. Trial order is shuffled; A/B assignment itself is not counterbalanced. The current package copies original-level WAVs without loudness matching. Only exported evaluation examples become trials, so a three-example smoke package contains three trials, not a full perceptual study.

For listener , correct responses in trials give . The descriptive null model is

The scorer uses SciPy's two-sided exact binomial test. Its two-sided p-value sums null probabilities of outcomes no more probable than the observed outcome, subject to the library's numerical convention. It is not simply the fraction correct.

Above-chance discrimination indicates audible differences under the study conditions. Failure to reject chance can arise from low power and does not establish perceptual equivalence. ABX also does not measure which sound listeners prefer.

6.2 Confirmatory hybrid comparisons — required, analysis not implemented

The phase protocol requires three seeds (1337, 2027, 3407), at least two effect families, a TCN within 10% of hybrid parameter count, and at least 10% improvement in both median ESR and MR-STFT, plus a paired source-bootstrap 95% interval excluding zero improvement.

For a bootstrap, sample source IDs with replacement, retain all paired model outputs and presets for each sampled source, recompute source means and model medians, then compute . A percentile interval uses the 2.5th and 97.5th percentiles of the resampled statistic.

This describes a candidate implementation of the required source bootstrap. Resample count, random seed, treatment of training seeds, multiple-family/metric comparisons, and the primary statistic must be frozen before confirmatory evaluation. If a baseline denominator is zero, relative improvement is undefined; report absolute difference and use a preregistered decision rule. Do not treat three training seeds or many presets of one source as independent musical performances.

The proposed perceptual phase requires at least 20 consenting listeners and 20 trials each, exclusions specified in advance, and a listener/source clustered analysis. Counterbalancing, power analysis, equivalence margins if claimed, and separate original-level/loudness-matched conditions remain protocol work. The present scorer does not implement that group analysis.

7. Future effect-specific diagnostics — proposed

These formulas give candidate measurements, not current output fields or frozen acceptance thresholds.

Diagnostic Candidate definition Needed protocol choices
IR error from impulse responses Impulse amplitude, duration, nonlinear applicability, alignment
Complex response error $\sum_k \hat H_k-H_k
Energy-decay curve Noise floor, available tail, fitting interval
Decay time If fitted EDC slope is dB/s, extrapolated Reliable decay range, band filters, truncation and noise correction
Harmonic distortion Input amplitude/frequency, harmonic masks, FFT leakage
Nonharmonic/alias energy Stimuli, leakage masks, harmonic folding rules, antialiased reference
DC offset $ N^{-1}\sum_n\hat y_n-N^{-1}\sum_n y_n
Automation discontinuity Peak sample/derivative discrepancy at declared parameter changes Reference control semantics, smoothing, transition stimuli

The alias-energy expression alone is not a standardized ASR implementation. Harmonics can fold onto legitimate bins, and noise/leakage can contaminate residual energy; define a specific validated measurement protocol before naming or comparing an alias score. Likewise, a short or truncated IR cannot support a reliable measured simply by fitting a line.
