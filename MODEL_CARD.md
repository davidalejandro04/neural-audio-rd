# Prototype model card

**High-gain v5 extension:** a separate 5,329-parameter conditional TCN targets an original synthetic cascaded preamp, with a 126-sample context, drive-only wet conditioning and exact external mix law. An opt-in zero-preserving TCN path subtracts its learned zero-input baseline. This adds computation without adding parameters and preserves silence structurally; historical checkpoints are unchanged. The [tracked configuration](experiments/high-gain.json) uses 32 procedural plucked training sources, eight validation sources, 12 independent test sources, and 120 epochs. Cabinet, EQ, delay and reverb are separate native DSP. No real guitar or hardware captures train this checkpoint; Marshall/Guns N' Roses describes the intended musical direction, not measured fidelity. See [v5 evidence](reports/high-gain-evidence.json) and the [rig guide](docs/HIGH_GAIN.md). The earlier v1 high-gain trial is retained locally, including its measured silence offset; v5 packages the zero-preserving revision.

**Purpose:** research infrastructure, synthetic system-identification experiments, and a local native/plugin preview. Production and perceptual acceptance remain incomplete.

**Architectures:** shallow causal Conv1D; unconditioned causal TCN; static FiLM-conditioned causal TCN; GRU; hybrid TCN/GRU/learned four-FIR-basis mixer; hybrid without GRU or without FIR. All take mono audio and normalized `[drive, mix]`. Exact mix=0 bypass is structural. Experiments train one effect family at a time; no device/effect embedding is implemented.

**Training:** procedurally synthesized dry audio; normalized tanh wet target in the executed benchmark. The 12-epoch CPU smoke run uses eight training, three validation and three held-out test sources. Best checkpoint is selected on validation ESR. No real recordings were used to train these checkpoints. The hybrid is the HTML report's architectural hypothesis implemented as a small prototype; its FIR path is too short for realistic reverberation.

**Evidence:** [initial results](reports/INITIAL_RESULTS.md), [recorded measurements](reports/smoke-evidence.json). Training history, checkpoints, test renders and exports are local in `runs/` and `exports/`. Artifact SHA-256 values identify local files. There was no existing Git commit at the start; later runs additionally record Python source hashes. A hash identifies an artifact, not a claim that it is publicly hosted.

**Runtime:** explicit per-stream audio history and GRU hidden state. Reset both at stream start or sample-rate changes. ONNX exports use fixed batch=1 and fixed block size, including explicit `hidden`/`next_hidden` for GRU models. Native C++ parity, state reset, WAV rendering, five irregular host callback sizes, stereo consistency, editor creation and VST3 state save/restore have been tested. The buffered plugin reports one model block of latency (128 samples for the default preview). Fast automation, smoothing and allocation inside the runtime DLL are not fully audited. Core waveform inference has no lookahead; host adaptation adds buffering latency.

**Current development models:** the completed P3 study uses three training seeds, two synthetic families and a parameter-matched conditioned TCN/full-hybrid comparison; its overall acceptance failed. The separate v2 development TCN has 2,617 parameters and enforces the exact dry/wet mix law by keeping Mix outside the learned wet path. It was trained under a new mixed-control protocol, achieved test ESR 0.00236, passed native parity/timing screens, and remains available as the Neural model option. Its original PyTorch timing gate failed and remains recorded. These changes are not a controlled ablation of P3.

**Reference baseline:** a paired dry/wet feature encoder with an eight-dimensional source-consistency latent predicts Drive/Mix. Its known-DSP decoder was evaluated on 72 cross-content trials over 12 synthetic test sources. Source-median ESR was 0.01616, compared with 0.16058 for a training-mean control baseline. It can also drive a frozen conditioned audio model or export a JSON preset. This is not a jointly trained reference-conditioned HyNeFX model and has no listening results.

**Limitations:** synthetic source and target generators; no aliasing analysis, real-capture evaluation, trained Temporal FiLM, or perceptual results. The full hybrid's utility differs by family. Official VST3 conformity passed for unloaded, TCN-loaded and hybrid-loaded cases, but target DAW acceptance remains pending. Float-WAV rendering preserves output without clipping or limiting. See [the native/reference guide](docs/NATIVE_AND_REFERENCE.html) and recorded evidence for exact scopes.

**Distribution:** external SDK sources remain in ignored `.deps/`; local preview builds include required runtime DLLs and observed license/notice files. Three publisher-declared CC0 GuitarJam DI excerpts are now bundled for auditioning, with source metadata and notices. Nothing has been installed to a DAW or published. The repository owner must choose a code/weights license and review dependency terms before distribution.

**Guitar distortion preview:** v4 opens a separately labelled conventional DSP pedal with 4x oversampling, smoothed input/drive/mix/output, DC blocking and low-pass tone controls. Crunch and Heavy process real dry GuitarJam samples live. This is a DSP effect, not a newly trained neural model. The learned v2 model remains selectable and its historical research results are unchanged. See [the guitar guide](docs/GUITAR_DISTORTION.html) for actual-signal checks and preset measurements.

**Sustained timing:** the packaged v2 mono/128-sample model completed a 600-second paced native test at 48 kHz. Its p99 was 0.6912 ms against a 2.6667 ms deadline, but it recorded 40 processing overruns and 296 scheduling misses (worst processing 8.7545 ms). Sustained acceptance failed; the preview remains experimental. The ordinary process-thread measurement does not substitute for a target audio-device callback test. Original P3 and PyTorch timing failures remain unchanged.
